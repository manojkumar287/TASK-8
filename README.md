# 📊 Power BI Sales Dashboard

## 🧾 Objective
Create an interactive dashboard to analyze and display sales performance by Region, Category, and over Time.

---

## 🛠 Tools Used
- Power BI Desktop
- Dataset: Superstore_Sales.csv

---

## 📈 Dashboard Features

### 🎯 KPIs (Cards):
- *Sum of Profit*
- *Count of Order ID*
- *Count of Product ID*
- *Count of Sales*
- *Count of Quantity*

### 📊 Visuals:
- *Line Chart*: Average of Sales by MonthYear
- *Bar Chart*: Sum of Sales by Region
- *Donut Chart*: Sum of Sales by Category

### 🧩 Slicer:
- *Region*: Central, East, South, West

---

## 🔧 Data Transformations
- Converted Order Date into Month-Year format.
- Created a SortMonth field for proper time-based sorting.
- Aggregated fields to create summary cards and charts.

---

## 📌 Insights
1. *West Region* had the highest overall sales (~0.73M).
2. *Technology Category* led in performance with 36.4% share.
3. *November 2014* saw a significant sales spike.
4. *South Region* recorded the lowest sales (~0.39M).
5. The slicer enables filtering the dashboard by *Region*.

## 📁 How to Use
1. Open Power BI Desktop.
2. Import the Superstore CSV file.
3. Perform date transformation in Power Query.
4. Add visual components and slicers as shown.
5. Format using colors and borders for readability.
